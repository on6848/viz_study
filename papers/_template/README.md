# 新しい論文ページの追加手順

このフォルダは新しいエントリを作るためのテンプレートです。実際の公開には使いません
（フォルダ名が `_` で始まるものは一覧に出ません／Jekyllでも無視されるため `.nojekyll` を置いています）。

## 手順

1. `papers/` 直下に `YYYY-MM-DD-短い英語スラッグ/` フォルダを作る（例: `papers/2026-09-16-resnet/`）。
2. `index.html` と `demo.js` をこのテンプレートからコピーして中身を書き換える。
   - 要約は **自分の言葉でオリジナルに書く**。原論文の文章・図表をそのまま転載しない。
   - デモで使うデータが「論文の実データ」ではなく説明用の合成データの場合は、
     デモ内に一言断り書きを入れる（既存ページ参照）。
3. ルート直下の `papers.json` に1件追加する:
   ```json
   {
     "slug": "2026-09-16-resnet",
     "date": "2026-09-16",
     "title": "Deep Residual Learning for Image Recognition",
     "authors": "He et al., 2015",
     "arxivUrl": "https://arxiv.org/abs/1512.03385",
     "oneLiner": "一言サマリー",
     "tags": ["CV", "ResNet"]
   }
   ```
4. コミットしてpushすれば、GitHub Pages側にも自動的に反映される（`index.html` が `papers.json` を読んでカードを生成する）。

## 各ページの定型セクション（`2026-09-15-attention-is-all-you-need/index.html` を参照）

- 一言でいうと
- 解きたかった問題
- 提案手法の核心
- 触って理解する：可視化デモ（+ 合成データである場合はその明記）
- 結果・インパクト
- 限界・批判点
- 学び・所感

## 可視化デモを作るときの指針

- 依存ライブラリはCDN経由（またはvanilla JS）。ビルドステップなしでGitHub Pagesにそのまま置けること。
- 色は `assets/css/style.css` で定義済みのCSS変数（`--series-1`〜`--series-8`、`--seq-100`〜`--seq-700` など）を使う。
- ホバーでのツールチップ、キーボード操作（tabindex + focus）、表での代替表示など、
  アクセシビリティに配慮する（既存デモを参考にする）。
- 手法の改善提案はユーザーから随時来るので、指摘されたら該当デモ・説明文を直す。
